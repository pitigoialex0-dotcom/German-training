# 🧠 Разбор кода и задания

Приложение сделано целиком сразу, но учиться по нему лучше **по шагам**, в таком порядке:

1. `words.csv` и `vocab.py`: как данные попадают в программу
2. `checker.py`: проверка ответа
3. `progress.py`: Лейтнер и сохранение
4. `app.py`: интерфейс
5. `tests/test_logic.py`: как проверять свой код

После каждого шага есть **задание**. Делай его сам. Готовых решений здесь нет, только подсказки. Если застрял, пришли мне свой код, я укажу, где ошибка.

## Общая картина

```
words.csv ──► vocab.py ──► список слов (list из dict)
                                   │
                                   ▼
   ты ──► app.py (интерфейс) ──► checker.py (верно / опечатка / неверно)
                │
                ▼
          progress.py ──► progress.json (коробки, счётчики, дни)
```

Каждый файл отвечает за одну вещь. `app.py` только показывает данные и принимает ответы, вся логика живёт в остальных трёх файлах. Поэтому логику можно проверять тестами без браузера.

## Шаг 1. `vocab.py`: чтение словаря

**Что делает:** читает `words.csv` и превращает каждую строку в словарь Python.

**Концепции Python:**

- **Словарь (`dict`)** хранит пары «ключ → значение»: `word["russian"]` → `"врач"`. Каждое слово хранится как такой словарь.
- **Список (`list`)** хранит элементы по порядку. Весь словарь — это список словарей: `words = [ {...}, {...} ]`.
- **Функция (`def`)** — кусок кода с именем. Принимает данные (параметры) и возвращает результат через `return`. Например, `make_key(word)` получает слово и возвращает `"der Arzt"`.
- **Цикл `for`**: `for line_number, row in enumerate(reader, start=2)` перебирает строки файла. `enumerate` при этом даёт ещё и номер строки, он нужен для понятных предупреждений.
- **Множество (`set`)**: `seen_keys` хранит уже встреченные слова. Проверка `if key in seen_keys` у множества мгновенная, даже если слов тысячи.
- **`try / except`** ловит ошибку, чтобы программа не упала: если файл не в UTF-8, ты увидишь понятное сообщение вместо красного текста ошибки.
- **Генератор списка (list comprehension):** `[word for word in words if word["lektion"] in lessons]` значит «возьми каждое слово, у которого урок из выбранных». Это короткая запись цикла `for` с `if` и `append`.
- **f-строки:** `f"Строка {line_number}: ..."` подставляют значения переменных прямо в текст.

**Почему JSON, а не SQLite:** JSON-файл можно открыть в любом редакторе и прочитать глазами, и он один в один превращается в словарь Python. Для SQLite пришлось бы параллельно учить второй язык, SQL. При твоих 1–2 тысячах слов JSON работает мгновенно.

## Шаг 2. `checker.py`: проверка ответа

**Что делает:** решает, правильный ли ответ, и прощает мелочи.

**Порядок проверки** в `check_answer`:
1. Точное совпадение → `correct`.
2. Совпадение после `normalize` (маленькие буквы, `ä → ae`, `ß → ss`, `ё → е`) → `correct` с подсказкой точного написания.
3. Разница в 1–2 буквы → `typo` (засчитано).
4. Иначе → `wrong`.

**Концепции Python:**

- **Методы строк:** `.lower()`, `.strip()`, `.replace()`, `.split()`. Строки в Python неизменяемы, поэтому каждый метод возвращает **новую** строку. Отсюда запись `text = text.lower()`.
- **Перебор словаря:** `for letter, replacement in REPLACEMENTS.items()` даёт сразу и ключ, и значение.
- **Ранний `return`:** как только ответ понятен, функция сразу выходит. Без кучи вложенных `if/else`.
- **Вложенные циклы** в `count_typos` (расстояние Левенштейна). Это самый сложный кусок кода в проекте, разбери его на бумаге. Для `kopf` → `kopp` построй таблицу 5×5: в каждой клетке минимальное число правок, чтобы превратить начало одного слова в начало другого. Ответ получится в правом нижнем углу.
- **`True` как число:** `(letter_a != letter_b)` даёт `True` или `False`, а в арифметике они равны 1 и 0.

**Почему короткие слова строже:** `Rock → Rick` — одна буква, но это уже другое слово. Поэтому в словах до 4 букв опечатки не прощаются (функция `allowed_typos`).

## Шаг 3. `progress.py`: Лейтнер и сохранение

**Что делает:** помнит, в какой коробке каждая карточка, когда её повторять, сколько было ошибок.

**Концепции Python:**

- **JSON ↔ словарь:** `json.load(f)` превращает файл в словарь, `json.dump(data, f)` обратно. `ensure_ascii=False` нужен, чтобы русские буквы в файле читались, а не превращались в `в`.
- **Даты:** `date.today()` — сегодня, `timedelta(days=3)` — промежуток в 3 дня. Дату можно прибавить: `today + timedelta(days=3)`.
- **Хитрость с датами-строками:** даты хранятся как `"2026-10-11"`. Строки в таком формате (год-месяц-день) сравниваются правильно: `"2026-10-09" < "2026-10-11"`. Поэтому `is_due` сравнивает просто строки.
- **`dict.get(key, default)`** возвращает значение или запасной вариант, если ключа нет. Так `get_card` выдаёт «новую» карточку, ничего не записывая.
- **`dict.setdefault(key, default)`** делает то же, но ещё и **записывает** запасной вариант в словарь. Его использует `record_answer`.
- **`min(...)`:** `min(card["box"] + 1, MAX_BOX)` не даёт коробке стать больше 5.
- **Случайный выбор с весами:** `random.choices(candidates, weights=weights)`. Слово из коробки 1 получает вес 5, из коробки 5 вес 1, поэтому трудные слова выпадают в 5 раз чаще.
- **Сортировка с `key`:** `rows.sort(key=lambda row: row["Ошибок"], reverse=True)`. `lambda` — это маленькая функция без имени, она говорит, по чему сортировать.
- **Цикл `while`** в `streak` идёт назад по дням, пока ты в этот день занимался.

**Защита файла:** `save_progress` сначала пишет во временный файл и только потом подменяет старый. Если программа упадёт посреди записи, старый прогресс останется целым.

## Шаг 4. `app.py`: интерфейс

**Главное, что нужно понять про Streamlit:** при **каждом** нажатии кнопки файл `app.py` выполняется заново, сверху вниз. Обычные переменные забываются. Поэтому:

- текущая карточка хранится в `st.session_state` (словарь, который Streamlit не стирает), см. функцию `get_task`;
- после ответа вызывается `st.rerun()`, чтобы сразу перерисовать страницу с результатом;
- кнопка «Дальше» ставит `task["word"] = None`, и при следующем запуске `get_task` выберет новое слово.

**Концепции Python и Streamlit:**

- **Виджеты:** `st.radio`, `st.button`, `st.text_input`, `st.multiselect` возвращают то, что выбрал пользователь. `if st.button(...)` срабатывает при нажатии.
- **Формы:** `with st.form(...)` позволяет отправить ответ клавишей Enter.
- **Колонки:** `st.columns(3)` даёт три колонки, в них три кнопки артиклей.
- **Функция как значение:** `format_func=MODE_NAMES.get`. Мы передаём саму функцию (без скобок!), и Streamlit сам вызывает её для каждого варианта.
- **Кортеж (`tuple`)** в `settings`: `(mode, tuple(lessons), only_due)`. Если хоть что-то в настройках поменялось, кортежи не равны, и начинается новое задание.
- **JavaScript внутри Python:** `speak_button` и `focus` вставляют маленькие скрипты. Это «трюки», в учебных целях их можно пропустить.
