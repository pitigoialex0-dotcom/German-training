# 🇩🇪 Deutsch lernen: тренажёр слов для Menschen A1–A2

Приложение в браузере для изучения немецких слов из **твоего собственного** словаря.

- 🃏 **Карточки** в двух направлениях: немецкий → русский и русский → немецкий. Ответ пишешь сам.
- 🎯 **Тренировка артиклей** der / die / das. Ошибки в артиклях считаются отдельно.
- 📦 **Интервальное повторение** по Лейтнеру: трудные слова появляются чаще, выученные реже.
- 📚 **Фильтр по урокам** (Lektion).
- 📊 **Статистика**: выученные слова, процент правильных, топ-10 трудных слов, серия дней 🔥.
- ✍️ **Умная проверка**: прощает мелкие опечатки, `ae/oe/ue/ss` вместо `ä/ö/ü/ß`, «е» вместо «ё».
- 🔊 **Произношение** голосом браузера.
- ⌨️ **Работа с клавиатуры**: ввёл ответ → Enter (проверить) → Enter (дальше).

## Установка (один раз)

### Шаг 1. Установи Python

1. Открой https://www.python.org/downloads/ и скачай последнюю версию Python (3.12 или новее).
2. Запусти установщик.
   - **Windows:** на первом экране **обязательно поставь галочку «Add python.exe to PATH»**, потом нажми «Install Now».
   - **macOS:** просто нажимай «Продолжить».
3. Проверь установку: открой терминал (как это сделать, см. шаг 3) и напиши:
   ```
   python --version
   ```
   Должно появиться что-то вроде `Python 3.13.0`. На macOS команда может называться `python3`.

### Шаг 2. Скачай проект

**Вариант без git (проще):**
1. Открой страницу репозитория на GitHub.
2. Пока код лежит в ветке `claude/german-learning-app-atp621`, выбери её в списке веток слева вверху (там, где написано `main`).
3. Нажми зелёную кнопку **Code → Download ZIP** и распакуй архив, например в «Документы».

**Вариант с git** (если он установлен):
```
git clone -b claude/german-learning-app-atp621 https://github.com/pitigoialex0-dotcom/German-training.git
```

### Шаг 3. Открой терминал в папке проекта

- **Windows:** открой папку проекта в Проводнике, кликни в адресную строку сверху, напиши `cmd` и нажми Enter. Откроется чёрное окно, уже в нужной папке.
- **macOS:** открой программу «Терминал», напиши `cd ` (с пробелом в конце), перетащи папку проекта в окно терминала и нажми Enter.

### Шаг 4. Создай виртуальное окружение

Виртуальное окружение — это отдельная «коробка» для библиотек этого проекта, чтобы они не смешивались с другими.

**Windows:**
```
python -m venv .venv
.venv\Scripts\activate
```

**macOS:**
```
python3 -m venv .venv
source .venv/bin/activate
```

Если получилось, в начале строки терминала появится `(.venv)`.

### Шаг 5. Установи библиотеки

```
pip install -r requirements.txt
```

Это займёт 1–2 минуты: скачается Streamlit (интерфейс) и pytest (для тестов).

### Шаг 6. Запусти приложение

```
streamlit run app.py
```

Браузер откроется сам на адресе http://localhost:8501. Если не открылся, скопируй этот адрес в браузер.

Чтобы **остановить** приложение, вернись в терминал и нажми `Ctrl + C`.

## Как добавлять слова

Слова хранятся в файле **`words.csv`**. Добавлять их можно двумя способами:

1. **В приложении**, на странице «➕ Добавить слово». Это самый простой способ.
2. **Прямо в файле.** Открой `words.csv` в VS Code, Блокноте, LibreOffice или Google Таблицах.

Столбцы файла:

| Столбец | Что писать | Пример |
|---|---|---|
| `german` | немецкое слово **без артикля** | `Arzt` |
| `article` | `der`, `die`, `das`; у глаголов, прилагательных и т.п. пусто | `der` |
| `plural` | множественное число (можно пусто) | `die Ärzte` |
| `russian` | перевод; если вариантов несколько, через `/` | `идти/ходить` |
| `english` | перевод на английский (можно пусто) | `doctor` |
| `lektion` | номер урока | `15` |
| `example` | пример предложения (можно пусто) | `Mein Kopf tut weh.` |

**Важно:**
- Номера уроков в шаблоне примерные. Поправь их под свой учебник.
- Если в примере есть запятая, весь пример должен быть в кавычках: `"Ich bin müde, aber glücklich."`. Excel, Google Таблицы и форма в приложении делают это сами.
- **Excel:** сохраняй через «Файл → Сохранить как → **CSV UTF-8**». Обычный «CSV» в русском Excel ломает буквы ä, ö, ü, ß. Разделитель «;», который ставит русский Excel, приложение понимает.
- **Google Таблицы:** «Файл → Скачать → CSV» и замени этим файлом `words.csv`.
- Если в файле что-то не так (неизвестный артикль, нет перевода, слово повторяется), приложение покажет жёлтое предупреждение с номером строки.

Новые слова появляются сразу: перезапуск не нужен, достаточно перейти на другую страницу или обновить вкладку.

## Как работает повторение (система Лейтнера)

У каждого слова есть отдельная карточка для каждого режима: DE→RU, RU→DE и артикль. Узнать слово проще, чем вспомнить его самому, поэтому прогресс по направлениям считается раздельно.

| Коробка | Когда повторять |
|---|---|
| 1 | сегодня (сюда попадают новые слова и все ошибки) |
| 2 | через 1 день |
| 3 | через 3 дня |
| 4 | через 7 дней |
| 5 | через 21 день |

- Правильный ответ переносит карточку на коробку выше.
- Ошибка возвращает карточку в коробку 1, и слово появится снова уже сегодня.
- Слово считается **выученным**, когда во всех его режимах карточка лежит в коробке 4 или 5.
- Галочка «Только слова к повторению» слева: если её снять, будут показываться все слова, но трудные всё равно чаще.

В режиме RU→DE существительное нужно писать **с артиклем**: `der Arzt`. Если само слово верное, а артикль нет, это считается ошибкой и попадает в статистику артиклей.

## Где хранится прогресс

В файле **`progress.json`** рядом с программой. Он создаётся сам после первого ответа.

- Не удаляй его, иначе прогресс пропадёт. Сделать резервную копию можно простым копированием файла.
- Начать заново: «📊 Статистика → ⚠️ Сбросить весь прогресс».
- Файл не загружается в git (он указан в `.gitignore`), поэтому обновление кода прогресс не затрёт.

## Тесты

Тесты автоматически проверяют, что проверка ответов и Лейтнер работают правильно. Запуск:
```
python -m pytest
```
Должно появиться `21 passed`. Запускай тесты после каждого изменения кода.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| `python не является внутренней или внешней командой` | Переустанови Python с галочкой «Add python.exe to PATH» или используй команду `py` вместо `python`. |
| `streamlit: command not found` / `не является командой` | Не включено окружение. Выполни команду активации из шага 4: в начале строки должно быть `(.venv)`. |
| В PowerShell ошибка «выполнение сценариев отключено» | Открывай `cmd`, как в шаге 3, а не PowerShell. |
| Кнопка 🔊 молчит | Лучше всего голос работает в Chrome и Edge. В Windows можно добавить немецкий голос: Параметры → Время и язык → Речь → Добавить голоса → Deutsch. |
| Вместо ä/ö/ü знаки вопроса | Файл сохранён не в UTF-8. Пересохрани его как «CSV UTF-8». |
| `Port 8501 is already in use` | Приложение уже запущено в другом окне терминала. Закрой его или открой http://localhost:8501. |
