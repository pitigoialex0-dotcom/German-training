# 🇩🇪 Deutsch A2: тренажёр для подготовки к Goethe-Zertifikat A2

Приложение в браузере в стиле Duolingo, заточенное под экзамен **Goethe-Zertifikat A2** и учебник Menschen.

**Что внутри**
- 🗺️ **Путь к экзамену**: 14 разделов по темам Goethe A2, в каждом станции: новые слова → артикли → Perfekt → 🏆 чекпоинт. Пройденные станции отмечаются звёздами ⭐, следующая открывается после предыдущей.
- 🎮 **Уроки как в Duolingo**: знакомство со словом, выбор из 4 вариантов, ответ вводишь сам. Ошибки возвращаются в конец урока. Комбо 🔥, очки опыта ⚡, уровни, звуки, конфетти.
- 🧭 **Темы**: прогресс по каждой теме экзамена, любую тему можно учить отдельно.
- 🎓 **Goethe A2**: формат экзамена и как его оценивают, отсчёт дней до даты, готовность по частям, тренажёры **Schreiben** (10 заданий с автопроверкой объёма и образцами), **Sprechen** (карточки Teil 1–3), **Hören** (диктант), **Redemittel** (68 готовых фраз).
- 📚 **312 слов уровня A2** по темам, с артиклями, множественным числом, формами Perfekt и примерами. Свои слова из Menschen добавляешь сам.
- 📦 **Интервальное повторение** по Лейтнеру и «Повторение дня».
- ✍️ **Умная проверка**: прощает опечатки, `ae/oe/ue/ss` вместо `ä/ö/ü/ß`. При этом ловит ошибки артикля и haben/sein в Perfekt.
- 🔊 Озвучка голосом браузера, ⌨️ управление с клавиатуры (Enter, цифры 1–4).

## Установка (один раз)

### Шаг 1. Установи Python

1. Открой https://www.python.org/downloads/ и скачай последнюю версию Python (3.12 или новее).
2. Запусти установщик.
   - **Windows:** на первом экране **обязательно поставь галочку «Add python.exe to PATH»**, потом нажми «Install Now».
   - **macOS:** просто нажимай «Продолжить».
3. Проверь установку: открой терминал (как это сделать, см. шаг 3) и напиши:
   ```
   python --version
   ```
   Должно появиться что-то вроде `Python 3.13.0`. На macOS команда может называться `python3`.

### Шаг 2. Скачай проект

**Вариант без git (проще):**
1. Открой страницу репозитория на GitHub.
2. Пока код лежит в ветке `claude/german-learning-app-atp621`, выбери её в списке веток слева вверху (там, где написано `main`).
3. Нажми зелёную кнопку **Code → Download ZIP** и распакуй архив, например в «Документы».

**Вариант с git** (если он установлен):
```
git clone -b claude/german-learning-app-atp621 https://github.com/pitigoialex0-dotcom/German-training.git
```

### Шаг 3. Открой терминал в папке проекта

- **Windows:** открой папку проекта в Проводнике, кликни в адресную строку сверху, напиши `cmd` и нажми Enter. Откроется чёрное окно, уже в нужной папке.
- **macOS:** открой программу «Терминал», напиши `cd ` (с пробелом в конце), перетащи папку проекта в окно терминала и нажми Enter.

### Шаг 4. Создай виртуальное окружение

Виртуальное окружение — это отдельная «коробка» для библиотек этого проекта, чтобы они не смешивались с другими.

**Windows:**
```
python -m venv .venv
.venv\Scripts\activate
```

**macOS:**
```
python3 -m venv .venv
source .venv/bin/activate
```

Если получилось, в начале строки терминала появится `(.venv)`.

### Шаг 5. Установи библиотеки

```
pip install -r requirements.txt
```

Это займёт 1–2 минуты: скачается Streamlit (интерфейс) и pytest (для тестов).

### Шаг 6. Запусти приложение

```
streamlit run app.py
```

Браузер откроется сам на адресе http://localhost:8501. Если не открылся, скопируй этот адрес в браузер.

Чтобы **остановить** приложение, вернись в терминал и нажми `Ctrl + C`.

## Как пользоваться

1. **Главная**: открой «⚙️ Настройки» внизу и укажи **дату экзамена** и цель XP в день.
2. **Путь**: нажми «▶ Начать станцию». Проходи станции по порядку, на станцию уходит 3–5 минут.
3. **Каждый день**: «🔁 Повторение дня» на главной. Это слова, которые пора повторить по Лейтнеру.
4. **Goethe A2**: раз в несколько дней пиши письмо (Schreiben) и проговаривай карточки Sprechen вслух.
5. **Статистика**: смотри слабые темы и топ-10 трудных слов.

Станция засчитывается, если ты решил с первой попытки хотя бы 60% заданий (чекпоинт: 80%). ⭐ — 60%, ⭐⭐ — 80%, ⭐⭐⭐ — без ошибок.

## Как добавлять слова

Слова хранятся в **`words.csv`**. Добавлять можно на странице **«📖 Словарь → ➕ Добавить слово»** или прямо в файле (VS Code, LibreOffice, Google Таблицы).

| Столбец | Что писать | Пример |
|---|---|---|
| `german` | слово **без артикля**; глагол в инфинитиве | `Arzt`, `fahren` |
| `article` | `der` / `die` / `das`, у не-существительных пусто | `der` |
| `plural` | множественное число с `die` (можно пусто) | `die Ärzte` |
| `perfekt` | только для глаголов: вспомогательный глагол + Partizip II | `ist gefahren` |
| `russian` | перевод; несколько вариантов через `/` | `идти/ходить` |
| `english` | перевод на английский (можно пусто) | `doctor` |
| `thema` | тема экзамена, как в списке ниже (пусто → «Мои слова») | `Wohnen` |
| `lektion` | номер урока Menschen (можно пусто) | `15` |
| `example` | пример предложения (нужен для диктанта) | `Mein Kopf tut weh.` |

Темы: `Person und Familie`, `Wohnen`, `Essen und Trinken`, `Einkaufen und Kleidung`, `Alltag und Zeit`, `Freizeit und Hobbys`, `Körper und Gesundheit`, `Arbeit und Beruf`, `Schule und Lernen`, `Reisen und Verkehr`, `Stadt und Dienstleistungen`, `Wetter und Natur`, `Feste und Feiern`, `Medien und Kommunikation`.

**Важно:**
- Пояснение в скобках в переводе необязательно при ответе: на «билет (на транспорт)» засчитается просто «билет».
- **Excel:** сохраняй через «Сохранить как → **CSV UTF-8**». Обычный «CSV» ломает ä, ö, ü, ß. Разделитель «;» приложение понимает.
- Если в файле ошибка (неизвестный артикль, нет перевода, дубликат), приложение покажет жёлтое предупреждение с номером строки.
- Новое слово с темой встаёт в конец своего раздела на пути.

## Откуда материалы и насколько им можно доверять

- **Формат экзамена** (`data/goethe_a2.json`) собран по официальным страницам и PDF goethe.de (Modellsatz, Übungssatz, Durchführungsbestimmungen, Wortliste). Скачать сами PDF напрямую не получилось, поэтому факты взяты из их поисковых выдержек. Что не удалось подтвердить, перечислено в приложении: «Goethe A2 → Экзамен → Источники». Перед экзаменом сверься с правилами своего экзаменационного центра.
- **Слова, задания Schreiben/Sprechen и Redemittel** составлены ИИ и прошли отдельную проверку на артикли, Plural, Perfekt и переводы. Ошибки всё равно возможны. Нашёл — исправь в `words.csv` и напиши мне.
- **«Готовность к экзамену»** — грубая оценка по твоей практике в приложении, а не прогноз баллов. Lesen приложение не тренирует: для него решай официальный пробный тест (Übungssatz) на goethe.de.

## Где хранится прогресс

В файле **`progress.json`** рядом с программой: коробки Лейтнера, XP, звёзды станций, сделанные письма, дата экзамена.

- Не удаляй его. Резервная копия — простое копирование файла.
- Начать заново: «📊 Статистика → ⚠️ Сбросить весь прогресс».
- Файл не загружается в git (`.gitignore`), поэтому обновление кода прогресс не затрёт. Прогресс из старой версии приложения подхватывается автоматически.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| `python не является внутренней или внешней командой` | Переустанови Python с галочкой «Add python.exe to PATH» или используй команду `py`. |
| `streamlit: command not found` | Не включено окружение: выполни команду активации из шага 4, в начале строки должно быть `(.venv)`. |
| В PowerShell «выполнение сценариев отключено» | Открывай `cmd`, как в шаге 3, а не PowerShell. |
| `AttributeError` про `st.navigation` или `width` | Старая версия Streamlit: `pip install -U -r requirements.txt`. |
| Кнопка 🔊 молчит | Лучше всего работает в Chrome и Edge. В Windows можно добавить немецкий голос: Параметры → Время и язык → Речь → Добавить голоса → Deutsch. |
| Вместо ä/ö/ü знаки вопроса | Файл сохранён не в UTF-8: пересохрани как «CSV UTF-8». |
| `Port 8501 is already in use` | Приложение уже запущено в другом окне. Закрой его или открой http://localhost:8501. |
